Lorsque vous activez la détection de l’activité utilisateur dans Ransomware Resilience, les identifiants actuellement enregistrés dans Console sont utilisés pour gérer vos collecteurs de données. Si vous avez précédemment activé la détection de l’activité utilisateur via Data Infrastructure Insights (DII) Workload Security, les identifiants de Console remplaceront ceux que vous utilisiez auparavant dans DII pour gérer les collecteurs de données.
