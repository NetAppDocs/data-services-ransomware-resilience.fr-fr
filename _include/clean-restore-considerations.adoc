* Vous pouvez effectuer une restauration propre uniquement pour les attaques basées sur le chiffrement (comportement utilisateur et entropie) et les attaques par comportement utilisateur suspect. La restauration propre n'est pas prise en charge pour les attaques de fuite de données et de destruction de données.
* Si l'environnement de récupération isolé ne dispose pas de capacité pour une nouvelle opération, l'opération est placée en file d'attente jusqu'à ce que de la capacité soit disponible.
+
** Vous pouvez surveiller à tout moment l'état des opérations de restauration propres actives et en file d'attente dans le tableau de bord Ransomware Resilience Recovery.


* Lorsque vous lancez une restauration propre, le volume d'origine est démonté, ce qui peut perturber l'accès aux IO.
