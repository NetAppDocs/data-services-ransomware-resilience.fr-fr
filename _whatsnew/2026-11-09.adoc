=== Gestion des extensions de fichiers bloquées

Ransomware Resilience permet désormais de personnaliser la liste des extensions de fichiers autorisées ou bloquées sur un workload lorsque vous avez activé l’option de protection *Block suspicious file extensions*. Grâce à cette amélioration, vous pouvez configurer le workload pour n’autoriser que certains types de fichiers sur la storage VM (SVM) ou pour bloquer certaines extensions de fichiers. Si vous migrez un workload existant utilisant FPolicy pour bloquer les extensions de fichiers suspectes vers Ransomware Resilience, il utilise par défaut une liste d’extensions plus ciblée, bien que vous puissiez personnaliser cette liste. Cette amélioration offre un contrôle plus granulaire sur l’option des extensions de fichiers et vous permet également de créer différentes listes pour différentes SVM.

Pour plus d’informations, voir link:https://docs.netapp.com/us-en/data-services-ransomware-resilience/task-file-extensions.html["Gérer les extensions de fichiers bloquées dans Ransomware Resilience"].
